# HarryPotter

## Description
Ce projet est une application web basée sur l'univers de Harry Potter. Elle permet aux utilisateurs de consulter des informations sur les personnages, les maisons, les sortilèges et bien plus encore.

## Prérequis
Avant de commencer, assurez-vous d'avoir installé les éléments suivants :
- Git
- [WAMP](http://www.wampserver.com/) pour un serveur local avec Apache, MySQL et PHP
- [phpMyAdmin](https://www.phpmyadmin.net/) (inclus avec WAMP)
